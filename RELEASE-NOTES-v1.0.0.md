# Forgeon Game Planner v1.0.0

**The complete game development planning tool for organizing your creative projects.**

---

## 🎉 First Official Release

Forgeon Game Planner is a comprehensive desktop application designed to help game developers organize every aspect of their projects, from initial concept to final release.

---

## ✨ Features

### 📊 Dashboard
- Real-time project statistics and overview
- Quick access to all project sections
- Visual progress tracking

### ✅ Task Management
- Create and organize tasks with priorities (Low, Medium, High)
- Track status: To Do, In Progress, Completed
- Set deadlines and monitor progress
- Filter and search capabilities

### 🎨 Asset Tracker
- Store and manage game assets (images, audio, video, documents, scripts)
- **Multi-format preview support**:
  - Images: PNG, JPG, GIF, WebP, SVG
  - Audio: MP3, WAV, OGG
  - Video: MP4, WebM
  - Documents: TXT, MD, JSON, XML, HTML, CSS, JS, TS, Python, GDScript, Lua, and more
- **Zoom controls** for document/script viewing
- Categorize by type: Art, Audio, Code, Design, Documentation
- IndexedDB storage for efficient file management

### 🎯 Milestone Planner
- Define project milestones and deliverables
- Track completion progress
- Set target dates for goals

### 🎭 Character Classes Manager
- Define character classes and types
- Document abilities, stats, and characteristics
- Organize game mechanics by class

### ⚙️ Mechanics Manager
- Document game mechanics and systems
- Define rules and gameplay elements
- Track implementation status

### 📖 Story Manager
- Organize narrative into acts and scenes
- Write and manage story content
- Track story progression

### 📝 Notes
- Quick note-taking for ideas and reminders
- Searchable note library
- Color-coded organization

### 🤖 AI Assistant (Local)
- **Optional** local AI integration with Ollama
- Requires manual setup (see documentation)
- Privacy-focused: runs entirely on your machine

---

## 📦 Installation

### Windows Portable (No Installation Required)

1. **Download** `Forgeon-Game-Planner-1.0.0-Windows-x64.zip` below
2. **Extract** the ZIP file to your desired location
3. **Run** `Forgeon Game Planner.exe`
4. **Start creating!**

No installation, no admin privileges needed. Run from anywhere, including USB drives.

### Verify Your Download

For security, verify the file integrity using the SHA256 checksum in `SHA256SUMS.txt`.

**Windows PowerShell:**
```powershell
Get-FileHash "Forgeon-Game-Planner-1.0.0-Windows-x64.zip" -Algorithm SHA256
```
